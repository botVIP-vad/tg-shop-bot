# Telegram-бот «Заказ сайтов»

Бот на **aiogram 3** с каталогом офферов (услуг), поддержкой изображений и приёмом заявок.

## Возможности

- Пользователь смотрит каталог офферов (кнопки → карточка с фото, описанием и ценой) и оформляет заказ (оставляет контакт + комментарий).
- Заявка автоматически уходит всем администраторам в личные сообщения.
- Админ через `/admin` или кнопку «⚙️ Админ-панель»:
  - добавляет новый оффер: название → описание → цена → фото (пошагово, всё хранится в SQLite);
  - смотрит список офферов, скрывает/показывает или удаляет любой из них.
- Данные хранятся в SQLite (`bot.db`), файл создаётся автоматически при первом запуске.

## Установка

1. Установите Python 3.10+.
2. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Скопируйте `.env.example` в `.env` и заполните:

   ```bash
   cp .env.example .env
   ```

   - `BOT_TOKEN` — токен, который выдаёт [@BotFather](https://t.me/BotFather) при создании бота.
   - `ADMIN_IDS` — ваш Telegram ID (и через запятую — ID других админов). Узнать свой ID можно у бота [@userinfobot](https://t.me/userinfobot).

4. Запустите бота:

   ```bash
   python main.py
   ```

## Структура проекта

```
tg_shop_bot/
├── main.py            # точка входа, запуск polling
├── config.py           # чтение токена/админов из .env
├── database.py          # работа с SQLite (офферы, заказы)
├── states.py            # FSM-состояния (добавление оффера, оформление заказа)
├── keyboards.py          # inline/reply клавиатуры
├── handlers/
│   ├── user.py           # каталог, оформление заказа
│   └── admin.py          # создание и управление офферами
├── requirements.txt
└── .env.example
```

## Как это использовать

- Как обычный пользователь: `/start` → «🌐 Заказать сайт» → выбрать оффер → «✅ Заказать этот сайт» → указать контакт и комментарий.
- Как админ: `/admin` → «➕ Добавить оффер» → следовать шагам (в конце нужно отправить именно фото, а не файл-документ, чтобы оно красиво отображалось в карточке).
